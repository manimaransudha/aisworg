# Terminology

Computer programs, procedures and possibly associated documentation and data pertaining to the operation of a computer system is called a software”.

Software engineering is defined as the application of a systematic, disciplined, quantifiable approach to the development, operation, and maintenance of software.

Software engineering is organised into 18 knowledge areas of which 3 are foundation areas. 

Foundation areas are

- Computing Foundations
- Mathematical Foundations
- Engineering Foundations

The software engineering knowledge areas are: 

- Software Requirements
- Software Architecture
- Software Design
- Software Construction
- Software Testing
- Software Engineering Operations
- Software Maintenance
- Software Configuration Management
- Software Engineering Management
- Software Engineering Process
- Software Engineering Models and Methods
- Software Quality
- Software Security
- Software Engineering Professional Practice
- Software Engineering Economics
